# Changelog

All notable changes to this project will be documented in this file.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses semantic versioning for its own tooling. Client support
remains independently locked to exact file hashes.

## [1.0.0] - 2026-09-25

### Added

- HTTPS activation-endpoint emulator with error, grant, fixed, and replay modes.
- Version-locked x86 and x64 static patch/status/restore utility.
- Recommended suspended-process launcher with WOW64 PEB image-base discovery.
- Reversible Windows hosts and current-user TLS trust setup.
- Protocol, patch, usage, contribution, and security documentation.
- Windows CI for Python 3.10 through 3.13.
